Reading the evidence

Timings use uninstrumented, randomized paired processes with identical verified output. Speedup is C++ time divided by Rust time. Confidence intervals and invalid or inconclusive outcomes remain visible.

Profiles separately execute strict decoding, tolerant decoding, in-memory NNTP BODY handling, and RAR5 metadata analysis through application classes. They include setup and output verification. They do not reproduce database, provider-network, or full production ingestion costs.

PHP charts show exclusive function cost; call-edge tables show inclusive cost. Native flamegraph width represents sampled CPU-clock period weights in nanoseconds, not elapsed wall time or the number of samples.

These fixture results do not establish production throughput or satisfy the project's 1.5× common-path and uncommon-p99 Rust adoption gate. This work publishes diagnostics; it does not adopt another replacement.
