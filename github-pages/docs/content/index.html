An indexer, with focused native components

The app remains a Laravel/PHP indexer. Rust supplies selected decoding, parsing, presentation, and diagnostic components. Article-ID fingerprinting uses native PHP; the withdrawn Rust candidate is retained only for explicit benchmarks. A Rust source file doesn't establish a speedup. Each comparison needs a defined baseline, matching output, representative inputs, and the cost of calling the implementation from the app.

The documentation separates source behavior from test results, and both from deployment or live publication. Read how to interpret the evidence before using a benchmark to choose hardware or worker counts.

Plan for a substantial local workload

For the intended personal setup, plan around 32–64 GB of RAM, a modern processor, NVMe storage, and a fast gigabit download connection. This planning target doesn't establish a measured minimum or throughput. The supplied service limits, database cache, verification scratch space, and provider connection allowance all affect capacity. The local deployment guide explains those settings before indexing starts.
