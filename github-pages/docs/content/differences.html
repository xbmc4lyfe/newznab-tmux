What this fork changes

This is a personal experimental fork of NNTmux. The upstream NNTmux project remains the main project, and its maintainers and contributors deserve the credit for the app, its community, and the work this fork builds on.

Scope. This page describes xbmc4lyfe/newznab-tmux at commit 4cd2b2f3fddff73c3df3b9a508ec3cde46f92ac7, compared with NNTmux/newznab-tmux master at 20400fe9822051a3ad60dacb887e0aacac77fae8. Newer upstream and fork commits are outside this snapshot.

The fork's own README describes focused work on release identification, processing, local deployment, and selected PHP-to-Rust experiments. It isn't a replacement project and doesn't speak for upstream maintainers.

How the histories relate

The comparison uses the common ancestor ef0e8c363f13cca5fb62506db64ccbbb329fde84. At this snapshot, upstream master has three commits beyond the fork, and the fork has 165 commits beyond upstream master. The three upstream-only commits are dependency updates, an updater update, and a season-pack fix. See the complete pull request and commit ledger for exact hashes and references.

The commit counts include upstream synchronization, merged project work, fixes, benchmark artifacts, and other changes. They're not a count of independent features or hand-written app lines. The fork's 161 merged pull requests include upstream sync PRs and an explicit adoption of upstream PR #1889. The full ledger keeps those references visible.

How to read these differences

Pull request titles are an index, not proof that every behavior remains active at this revision. The ledger includes every merged fork PR visible at the snapshot, its merge commit hash, changed-file inventory, and compare references. Current source links on the processing, release identification, and deployment pages show representative behavior. Tests, CI results, merged source, deployed services, and observed results are separate evidence states.

The upstream project is the foundation and remains the place to follow for the main NNTmux project. These notes describe one fork's work and experiments. They don't express upstream priorities or compare project quality.
